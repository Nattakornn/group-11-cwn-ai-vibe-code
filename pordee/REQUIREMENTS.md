# Requirements · พอดีพอร์ต (Pordee Port · US Stock Insight)

ที่มา: `USER-STORIES.md`, `interview/INTERVIEW.md` รอบที่ 1 และ `interview/OWNER-ANSWERS.md` รอบที่ 2

**วิธีอ่าน**

- **FR** = ระบบต้องทำอะไรได้ · **BR** = กฎของธุรกิจที่มีตัวเลข · **NFR** = ต้องดีแค่ไหน และวัดอย่างไร
- **[D]** = คุณกานต์หรือทีมของคุณกานต์พูดเอง บอกตำแหน่งท้ายป้าย: `[D] §6` = หัวข้อใน `OWNER-ANSWERS` · `[D] บ.19` = บรรทัด 19 ใน `INTERVIEW`
- **[R]** = กฎทั่วไป (คณิตศาสตร์ หรือหลักของตลาดหุ้น) ที่ทีมใช้ โดยคุณกานต์ยังไม่ได้ยืนยัน จึงติด ⚠️ คู่กันเสมอ
- **⚠️ สมมติ A-xx** = ยังไม่มีคำตอบ หรือทีมกำหนดเอง ดูตารางสมมติฐานท้ายไฟล์
- เรื่องที่ลูกค้าขอแต่คุณกานต์ยังไม่ได้ยืนยัน นับเป็น ⚠️ ไม่นับเป็น [D]
- เวลาเป็นเวลาไทยทั้งหมด · "คืน 26 พ.ย." = รอบตลาดที่เริ่มเย็นวันที่ 26 ตามเวลาไทย · ราคาหุ้นและอัตราแลกเปลี่ยนมาจากข้อมูลจำลองใน §1 และ §6 ไม่ใช่ข้อมูลจริง
- ✓ = ได้ / แสดง / ส่ง · ✗ = ไม่ได้ / ไม่แสดง / ไม่ส่ง
