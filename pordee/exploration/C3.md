- **การคืนค่า:** บีม — ขาย ZA01 5 @ $130 (id 29) แล้วลบทันที ตรวจแล้วกลับเป็น ZA01 20 / avg 120.18 / ฿83,124.50 / realized 0.00 · ค่าธรรมเนียมฝนคืนเป็น 0.15% / $1.00 แล้ว · **รายการของฝน (ZA06–ZA10, OLDC, id 10–27) ยังค้างอยู่** ให้ reset ของ C7 ล้าง (ฝนต้องว่างก่อน E140–E142)
- เงินบาทของล็อตที่ขายบางส่วนปัดไม่เป็นแบบครึ่งขึ้น (฿62,343.37) → ยอดรวมบาทของคนที่ขายบางส่วนเพี้ยนสะสมได้
- จดรายการวันที่ในอนาคตได้ และดึงอัตราแลกเปลี่ยนของวันอนาคต (35.0000 ของ 31 ธ.ค.) มาคิดต้นทุนบาท + นับเป็นหุ้นที่ถือวันนี้ → ต้นทุน/สิทธิ์ปันผลผิดได้ (X4)
- กำไรที่ "รับรู้แล้ว" เปลี่ยนย้อนหลังเมื่อจดซื้อย้อนวัน (ZA07: $48.00 → −$201.50) ตรงสูตร A-06 แต่ลูกค้าอาจงง
- ข้อความ error ไม่ตรงสาเหตุ: ราคา 5 ตำแหน่ง → "ราคาต้องมากกว่า 0" · ค่าธรรมเนียมผิดทุกแบบ → "ข้อมูลไม่ถูกต้อง"
- ยอมให้ค่าธรรมเนียม 99.9999% · จดวันเสาร์ได้โดยไม่เตือน
- ยังไม่ได้ลอง (หมดเวลา): ขาย 14.9999 → 0.0001 · ลบต้องกด 2 ครั้งใน UI · แก้ราคาล็อต (PATCH) · กดบันทึกซ้ำเร็ว ๆ ในฟอร์ม UI · ลบล็อตซื้อจนจำนวนติดลบ
- ใช้ API ตรง (ด้วย cookie ผู้ใช้) แทนการกรอกฟอร์มส่วนใหญ่ จึงไม่ได้จดข้อความ error ในหน้าจอทุกตัว (ที่เห็นในจอ: ส่งเปล่า)

### ถามลูกค้า
1. จดรายการ "วันที่ในอนาคต" ควรทำได้ไหม ถ้าได้ ควรนับเป็นหุ้นที่ถือวันนี้และใช้อัตราแลกเปลี่ยนวันไหน
2. จดวันเสาร์/อาทิตย์ (ตลาดปิด) ควรเตือนหรือห้ามไหม
3. ค่าธรรมเนียมของฉัน ควรมีเพดานสมเหตุสมผล (เช่น ≤ 5%) ไหม ตอนนี้ใส่ 99.9999% ได้
4. ต้นทุนบาทของหุ้นที่ขายไปบางส่วน คิดแบบไหน (สัดส่วน × ต้นทุนบาทรวม แล้วปัดครึ่งขึ้น?)
