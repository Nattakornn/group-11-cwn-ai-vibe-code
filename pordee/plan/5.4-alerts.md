# 5.4 แจ้งเตือน ช่วงเงียบ กล่องแจ้งเตือน และอีเมล

**ขอบเขต:** BR-20, BR-21, BR-33–BR-37 · FR-21–FR-26 · NFR-17 · กฎ R19 R41 R46–R61 ใน `EXPLORATION.md` ส่วน C
**ระดับ (ส่วน E):** F12 แจ้งเตือน = P1 · F14 กล่องแจ้งเตือน = P1 · F13 ช่วงเงียบ = P2 · F15 อีเมลจำลอง = P2

**วิธีทำให้เกิดแจ้งเตือน (ใช้ทุกการ์ด เรียกว่า "รอบตรวจ"):**
1. `POST /api/test/feed {symbol, mode:"price", price, clearCache:true}`
2. `GET /api/stocks/:symbol` ให้ราคาเข้าที่พัก
3. `POST /api/test/tick`
4. ก่อนรอบตรวจถัดไป เลื่อนนาฬิกา +1 นาทีด้วย `POST /api/test/clock` (โควตา 5 ครั้ง/นาทีใช้ร่วมกันทั้งเว็บ ดู R19)

ZALR ปิดวันก่อน **$200.00** · % = (ราคา − 200.00) ÷ 200.00 × 100 · ทุกการ์ดเริ่มด้วย `POST /api/test/reset` (นาฬิกา 6 พ.ย. 2569 22:00 เว้นแต่ระบุ) · `alert_events` และ `email_outbox` ว่างหลัง reset
